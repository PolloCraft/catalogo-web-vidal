# Marcas Distribuidoras — Logos

Coloca aquí los logos de las marcas distribuidoras en formato **PNG** con fondo transparente.

## Especificaciones

| Propiedad | Valor |
|-----------|-------|
| Formato   | PNG con transparencia |
| Ancho     | 200 px |
| Alto      | 60 px |
| Resolución| 72 dpi (mínimo) |
| Fondo     | Transparente |

## Nomenclatura

Usa el **nombre exacto de la marca** en minúsculas, sin espacios, con guiones si es necesario:

```
public/distributors/
  stanley.png
  truper.png
  philips.png
  3m.png
  festool.png
```

## Notas

- El carrusel en home muestra los logos en escala de grises y a color al hover.
- Si una marca no tiene logo PNG, se muestra su nombre como texto.
- Máximo recomendado: 12 marcas en el carrusel.
