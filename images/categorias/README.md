# Imagenes de Categorias

Coloca aqui las imagenes de cada categoria del catalogo.
Medida recomendada: **300 x 400 px** (vertical/portrait)

## Archivos esperados

| Archivo | Categoria |
|---------|-----------|
| ferreteria.jpg | Ferreteria |
| iluminacion.jpg | Iluminacion |
| electricos.jpg | Articulos Electricos |
| adhesivos.jpg | Adhesivos |
| seguridad.jpg | Seguridad Industrial |
| campana-escolar.jpg | Campana Escolar |
| generico.jpg | Imagen generica por defecto |

## Nota

- Si no colocas una imagen, el sistema usa la imagen generica
- Formatos soportados: .jpg, .jpeg, .png, .webp
- El nombre del archivo debe coincidir con el ID de la categoria en categories.json
- Las imagenes se muestran en un carrusel horizontal con el nombre superpuesto abajo
