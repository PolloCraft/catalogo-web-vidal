# Carpeta de Imagenes

Coloca tus imagenes en las subcarpetas correspondientes.

## Estructura

```
images/
├── banners/       ← Imagenes del hero/banner principal
├── productos/     ← Imagenes individuales de cada producto
└── categorias/    ← Imagenes de categorias del catalogo
```

## Formatos soportados

`.jpg`, `.jpeg`, `.png`, `.webp`

## Nota importante

Estas imagenes son las que el sitio usara para mostrar en cada seccion.
Asegurate de colocar los archivos con el nombre exacto indicado en cada README de las subcarpetas.
