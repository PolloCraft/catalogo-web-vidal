# Imagenes del Banner (Hero)

Coloca aqui las imagenes de fondo del carrusel principal.

## Archivos esperados

| Archivo          | Uso                         | Medida recomendada |
|------------------|-----------------------------|---------------------|
| `banner-1.jpg`   | Slide 1: Ferreteria         | 1920 x 800 px      |
| `banner-2.jpg`   | Slide 2: Precios mayoristas | 1920 x 800 px      |
| `banner-3.jpg`   | Slide 3: Campana escolar    | 1920 x 800 px      |

## Recomendaciones

- Formato: `.jpg` o `.webp` (mejor compresion)
- Proporcion: **21:9** (aproximado)
- Las imagenes se muestran con un overlay oscuro al 70% para que el texto sea legible
- Evitar textos o logos en la imagen, ya que el overlay los oscurece
